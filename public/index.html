This dashboard manages its own Codex CLI jobs. It does not switch accounts in an already-running Codex desktop or IDE session.

How switching works

  1. Each account uses a separate local login directory.
  2. Jobs use available accounts, up to your concurrency limit. Overlapping workspaces run one job at a time.
  3. On a reported usage limit, the account cools down and eligible jobs retry with another account.
  4. Write-enabled jobs pause for review unless you explicitly allow automatic write retries.

Retries start a fresh Codex session with the original prompt and a reminder to inspect existing work. They do not transfer the previous conversation.
